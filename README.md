# humbleangmoh.xyz

Static personal site. No framework, no build.

## Stack

- Plain HTML + CSS + a sprinkle of vanilla JS for theme toggle
- GitHub Pages (custom domain `humbleangmoh.xyz` via `CNAME`)

## Run

```bash
python3 -m http.server -d . 8080
# open http://localhost:8080
```

## Deploy

GitHub Pages auto-deploys from `main`. See `CLAUDE.md` for the draft → preview → push protocol.
